# StarCraft Alpha (1996) — visual reference collection

Purpose: document visual references for **Scalfagus**, a proposed StarCraft Alpha-style skin/mod for Wargus / Stratagus.

**Important:** This is a *reference catalog*, not a licensed game-asset pack. Screenshots and sprites from StarCraft remain Blizzard intellectual property, even if hosted by fans. Do not redistribute them as bundled game assets without permission. Download/review original resources privately and use independently created artwork or appropriately licensed alternatives for distributable builds.

## Historical distinction

- **Early 1996 / E3 1996:** Warcraft II-like side panel, purple organic Zerg designs. Highest-priority target for the project.
- **Late 1996 / 1997:** later experimental interface and tilesets; useful context, **not interchangeable** with E3 build.
- **Fan reconstruction:** recreation that must not be mislabeled an original Blizzard screenshot.
