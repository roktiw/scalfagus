# Scalfagus

**Simple Surface, Deep Simulation.** Original retro isometric pixel-art RTS with autonomous settlement, battlefield command and real first-person unit possession in **one authoritative world**.

## Project state

**S0 — development bootstrap branch.** A Mono-Blue toolchain seed is being implemented in draft branch feat/mono-blue-seed-pr01; prior main contains design/research. **No playable game, Godot engine benchmark or completed FPS has yet been demonstrated.**

## Three initial civilizations

| Stable ID | Short | Mid | Full backronym |
|---|---|---|---|
| ORG / org | Organs | Organites | Organites Reproductive Generalismus |
| MAN / man | Manus | Manusians | Manusians Augmented Navigators |
| ETH / eth | Eters | Etherans | Etherans Transcendent Hypervisors |

Distinct, individually specialized units — no mandatory hive mind. Faction-native transport: ORG mother carriers loaded on the move; MAN modular conveyor networks; ETH mobile couriers and stationary pylon hubs. Balancing and detailed production rules are still proposals.

## One Hero, three observation modes

Every player starts with a Hero and one of three open career starter kits: Engineer, Commander or Specialist. A common skill graph allows pivots across all three. Overlord runs economy + RTS; Direct Unit provides top-down action-RPG control; FPS gives Dungeon Keeper-like first-person control of the **same existing Hero**, without duplicate game state. All three are required in small form for the intended MVP.

## Technology direction

- Native Godot 4.7.2 Standard as prototype engine; Recoil remains a benchmark challenger.
- Node.js 24 LTS and pnpm 12.7.0 for future TypeScript developer toolchain and schema validation.
- Runtime uses GDScript for native actor state and controls; YAML -> validated JSON generated by offline TS tooling in a future iteration.
- Optional React/Vite Studio and Tauri 2 launcher are deferred; native standalone game does not require them.

## S0 bootstrap branch quickstart

Requires Node.js. For full developer environment, target Node 24 LTS and pnpm 12.7.0; standalone Godot 4.7.2 will be required starting with S1.

~~~bash
git clone https://github.com/roktiw/scalfagus.git
cd scalfagus
git switch feat/mono-blue-seed-pr01
node scripts/doctor.mjs --repo
node scripts/verify-seed.mjs
node --test scripts/tests/seed.test.mjs
~~~

Full toolchain check after installing Godot/pnpm on a suitable machine:

~~~bash
./scripts/bootstrap.sh --check
# Windows:
# pwsh -File scripts/bootstrap.ps1 -Check
~~~

**S0 limitation:** No apps/game/project.godot exists yet. The dev:game script intentionally reports that S1 needs to create the Godot project. No pnpm-lock.yaml or TypeScript packages are falsely claimed here; those require actual dependency resolution and clean-install checks.
