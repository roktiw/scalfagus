# MAN Barracks — infantry production

**Role:** first buildable MAN structure; worker spends real HQ Matter at legal command acceptance, performs construction on dry reachable ground; completed building trains Rifleman and counts for victory. The **unfinished site does not** count as victory. Construction pauses when the worker leaves.

**Visual:** squat blue/white rectangular modular hangar, dark recessed door, warm orange interior/lamps, strong 1990s RTS silhouette. It must be visually different from the Command Core while clearly manufactured by MAN.

**Production states:** placement ghost and **real 3×3 footprint**, scaffold with construction progress, finished, train queue activation, damage and destruction. Keep troops spawning near a physically correct door. Frame size is a proposal, not established production art.

**Pending:** no shippable Barracks sprites exist yet; `assets/` intentionally records this instead of borrowing the lander and mislabelling it.
