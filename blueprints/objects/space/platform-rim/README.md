# Floating-space-platform rim and underside — universal world frame

**DEC-030**: ALL playable maps, including the jungle, are visibly vast **stationary floating platforms in space**. This does not imply a flying playable unit, spherical planet or moving battlefield. MVP0 still has a square 64×64 planar walkable deck with **hard invisible world-boundary colliders**, visually supported by a clear four-sided rim.

**Visual:** brown layered soil, massive hanging roots through aged metal trusses, inactive thrusters and a subtle distant Earthlike planet among low-contrast stars. This is scenery, not an extra building, winner condition or economy source.

**Pending:** modular top-edge/corner, profile, underside and background visual packs. Keep decoration outside the gameplay grid from affecting map pathing/collisions.
