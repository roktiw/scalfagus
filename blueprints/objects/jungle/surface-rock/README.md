# Surface rock — finite SOLID deposit

**Gameplay:** workers mine a finite source into counted Matter, carry it physically and deposit at their own HQ. All source IDs, coordinates and amounts stay in `design/mvp-verdant-divide-map.yaml`. A decorative stone **must never** be mistaken for a selectable resource node.

**Art:** dark slate/grey angular outcrop with a small warmer exposed mining face, contrasting against brown earth. Animated mining dust/sparks should be separate. The current 56×36 five-view sheet is an engineer-made placeholder, not validated rotational art.

**Collision and interactability** come from semantic world data, never sprite transparency. Readability test: one glance distinguishes deposit from tiny cosmetic pebbles.
